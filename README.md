# Apneist Pro — brand kit

The logo, the colours and the type of **Apneist Pro**, the social network for freedivers (https://apneist.pro), and the rules for using them.

## The symbol

A bubble: a disc with two openings of light — one at its heart, one rising off its shoulder. It is the app's icon, the loading mark, the ring round a story. It is never redrawn, recoloured outside the palette below, rotated, or given a shadow or an outline.

## Files

```
svg/   vector — use these wherever you can
png/   raster at 2× for places that can't take an SVG
pdf/   for print
```

Each in three layouts and five colourings:

| Layout | File | Where |
| --- | --- | --- |
| Horizontal | `apneistpro-horizontal-*` | headers, footers, partner strips |
| Stacked | `apneistpro-stacked-*` | square placements, posters, covers |
| Symbol | `apneistpro-symbol-*` | icons, avatars, favicons, 32 px and under |

| Colouring | Use on |
| --- | --- |
| `on-dark` | deep blue and dark photos — the default |
| `on-light` | white and light backgrounds |
| `mono-white` | any dark background when colour is not possible |
| `mono-black` / `mono-dark` | print, embossing, one-colour media |
| `symbol-aqua` | the symbol alone in the brand aqua |

## Type

**Manrope** for everything; **Unbounded** for the wordmark and the big numbers. Both are open (Google Fonts).

## Clear space and size

Keep clear space around the logo equal to the height of the symbol. The horizontal logo is never narrower than 120 px on screen or 30 mm in print; the symbol alone never smaller than 16 px.

## Please don't

Stretch it, tilt it, put it on a busy photo without the deep backing, change its colours, add effects, or write "Apneist Pro" in another face next to it. The name is written **Apneist Pro** — two words, capital A and P; "apneistpro" only in handles and URLs.
